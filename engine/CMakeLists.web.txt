# LeirEngineCore — web-safe static subset of the engine (Fase 6 / M3 + M4).
# Renders through the RHI (WebGPUBackend + BackendFactory); excludes the
# Vulkan/D3D12 backends. SoLoud audio runs on wasm via the real
# AudioEngine/AudioClip/SoLoudBackend/SoundPlayer + AudioSource/AudioListener
# (MiniAudio -> WebAudio, linked PRIVATE soloud from cmake/AudioTooling.cmake).
# Jolt physics runs on wasm via the real PhysicsWorld.cpp
# (JobSystemSingleThreaded under __EMSCRIPTEN__) + RigidBody/Collider. The
# desktop engine keeps its own target in CMakeLists.txt.
# This file is include()d by the standalone Emscripten projects
# (examples/WebEngineDemo), which must already have fetched glm, nlohmann_json,
# stb, Jolt and SoLoud with the same tags as dependencies/CMakeLists.txt.
